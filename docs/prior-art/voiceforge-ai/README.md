# VoiceForge AI

Local AI voice notebook that records your spoken ideas, transcribes, structures, and connects them to your projects.

## User Dream
Users wish they could talk to their computer and have ideas turned into actionable notes without typing.

## Problem
Voice memos pile up unprocessed. Transcription apps are cloud-dependent or don't structure content.

## Target Users
Executives, writers, consultants, journalists, field researchers.

## Core Features
- One-click voice capture
- Local Whisper transcription
- AI structuring into notes/tasks/ideas
- Project-based organization
- Voice commands
- Offline mode

## Desktop-First Advantage
Desktop has microphone, file system, and can run Whisper locally without cloud costs/privacy concerns.
